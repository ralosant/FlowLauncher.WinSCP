This plugin let you launch [WinSCP](https://winscp.net/eng/index.php) sessions from [Flow Launcher](https://www.flowlauncher.com/).

#How to use it
1. Install this plugin via `pm install WinSCP Launcher`
2. After intallation, use:  `winscp Session_Name`

*. With portable version: Edit config.json file in the plugin folder and set the the WinSCP folder path. 

Based on [HelloWorldPython](https://github.com/Flow-Launcher/Flow.Launcher.Plugin.HelloWorldPython) and [Wox-Plugin-Kitty](https://github.com/Wox-launcher/Wox.Plugin.Kitty).
